# Privacy Policy - Smile Anti-Links Bot



## 1. Information Collected
Smile Anti-Links Bot ("the Bot") collects the following data to function properly:
- **Server IDs** – to store configuration settings per server.
- **User IDs** – to log moderation actions when configured.
- **Message content** – temporarily processed in real time to detect links; messages are not stored permanently.

## 2. How Data Is Used
- Server and user IDs are used only to apply the correct settings and moderation actions.
- Message content is checked only at the moment it is sent and is not retained after processing.
- No personal data is shared with third parties.

## 3. Data Storage
Configuration data is stored securely. Logs are kept only if enabled by server administrators and may be periodically deleted.

## 4. User Rights
You may request removal of your server's data by removing the Bot from your server. For any data-related requests, contact the developer.

## 5. Changes to This Policy
This Privacy Policy may be updated occasionally. Continued use of the Bot implies acceptance of any changes.
